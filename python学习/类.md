# Python 类（class）

相当于 Java 的**类**，但更灵活：无 `new`、无真正的 `private`、无接口（靠鸭子类型）、支持多继承。

## 定义与实例化

```python
class Dog:
    species = "犬科"           # 类属性：所有实例共享

    def __init__(self, name, age):   # 构造方法（对应 Java 构造器）
        self.name = name             # 实例属性
        self.age = age

    def bark(self):                  # 实例方法，第一个参数必须是 self
        return f"{self.name} 汪汪"

d = Dog("旺财", 3)    # 实例化：不需要 new
print(d.name)         # 旺财
print(d.bark())       # 旺财 汪汪
print(Dog.species)    # 犬科（类属性）
```

- `self` 对应 Java 的 `this`，但**必须显式写在方法第一个参数**
- 实例化**没有 `new`**，直接 `类名()`

### 构造方法与「重载」

Python **没有构造方法重载**，也没有「自动生成空参构造」——想支持多种传参方式，用**默认参数**代替：

```python
class Dog:
    def __init__(self, name="", age=0):   # 默认参数，一个构造顶多个
        self.name = name
        self.age = age

Dog()             # 空参 OK
Dog("旺财", 3)    # 带参 OK
```

| 场景 | Java | Python |
|------|------|--------|
| 不写构造器 | 编译器生成无参构造 | 可直接 `X()` 无参实例化 |
| 写了带参构造 | 无参构造消失 | `X()` 报 `TypeError` |
| 想要多种构造 | 构造器重载 | 默认参数替代 |

> 写了带参 `__init__` 后就不能再空参调用（和 Java「写了有参构造，无参构造就没了」一致）。

## 属性：实例 vs 类

| 类型 | 写法 | 归属 | Java 对应 |
|------|------|------|-----------|
| 实例属性 | `self.x`（在 `__init__` 里） | 每个实例独有 | 实例字段 |
| 类属性 | 类体内直接写 `x = ...` | 所有实例共享 | `static` 字段 |

```python
class Cat:
    count = 0            # 类属性

    def __init__(self):
        Cat.count += 1   # 通过类名访问/修改类属性

Cat("a"); Cat("b")
print(Cat.count)         # 2
```

## 访问控制（没有真正的 private）

Python 靠**命名约定**，不是强制：

| 写法 | 含义 | Java 对应 |
|------|------|-----------|
| `self.x` | 公开 | `public` |
| `self._x` | 约定「保护」，别碰但能访问 | `protected`（靠自觉） |
| `self.__x` | 名称改写为 `_类名__x` | `private`（仍可绕过） |
| `self.__x__` | 魔术方法，别自定义 | — |

```python
class User:
    def __init__(self):
        self.public = 1
        self._prot = 2
        self.__priv = 3    # 实际存成 _User__priv

u = User()
u.__priv            # AttributeError!
u._User__priv       # 3（名称改写，仍能访问）
```

## 魔术方法（dunder，双下划线）

| 方法 | 触发 | Java 对应 |
|------|------|-----------|
| `__init__(self)` | 构造 | 构造方法 |
| `__str__(self)` | `print()` / `str()` | `toString()` |
| `__repr__(self)` | `repr()` / 调试显示 | 更底层的 `toString()` |
| `__eq__(self,o)` | `==` | `equals()` |
| `__lt__(self,o)` | `<` | `compareTo()` |
| `__len__(self)` | `len()` | `size()` |
| `__getitem__(self,i)` | `obj[i]` | `get(i)` |
| `__iter__(self)` | `for` 遍历 | `iterator()` |
| `__add__(self,o)` | `+` | 无（运算符重载） |
| `__call__(self)` | `obj()` 可当函数调 | 函数式接口 |

```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __str__(self):
        return f"({self.x}, {self.y})"
    def __eq__(self, other):
        return self.x == other.x and self.y == other.y
    def __add__(self, other):
        return Point(self.x + other.x, self.y + other.y)

print(Point(1, 2))                    # (1, 2)
print(Point(1, 2) == Point(1, 2))     # True
print(Point(1, 2) + Point(3, 4))      # (4, 6)
```

## `__dict__`：实例属性字典

`__dict__` 是对象的**属性字典**，存实例的所有实例属性。它**不是**显示方法，别和 `__str__` 混淆。

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

d = Dog("旺财", 3)
print(d.__dict__)         # {'name': '旺财', 'age': 3}

d.__dict__["age"] = 5     # 等价于 d.age = 5
print(d.age)              # 5
```

- `obj.__dict__` → 属性名到值的字典；类也有 `__dict__`（存类属性 + 方法）
- 可直接改 `obj.__dict__["x"] = v`，等价于 `obj.x = v`
- 用途：调试查看属性、动态增删属性、反射

> ⚠️ 对应关系：`__str__` / `__repr__` 才对应 Java 的 `toString()`（`print(obj)` 时被调用）；`__dict__` 是「属性字典」，不是 toString。

## 继承

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return "..."

class Dog(Animal):                    # 继承 Animal
    def __init__(self, name, breed):
        super().__init__(name)        # 调父类构造 = Java super()
        self.breed = breed
    def speak(self):                  # 方法重写
        return f"{self.name} 汪汪"

print(Dog("旺财", "金毛").speak())    # 旺财 汪汪
```

**多继承**：`class C(A, B)` 同时继承多个类（Java 类只能单继承，靠接口补）。

```python
class Flyable: ...
class Swimmable: ...
class Duck(Flyable, Swimmable): ...   # Python 支持多继承
```

## 多态与鸭子类型

Python 没有接口，**不关心对象是什么类型，只关心它有没有这个方法**（鸭子类型）：

```python
def make_sound(animal):
    return animal.speak()    # 只要有 speak() 就能传，不管是不是 Animal 子类

# 相当于 Java 的「接口 + 多态」，但无需显式 implements
```

> ↔ Java：必须 `implements Animal` 才能传入；Python 只要「长得像」即可。

## 类方法 / 静态方法 / 实例方法

```python
class MyClass:
    count = 0

    def instance_method(self):      # 操作实例，第一个参数 self
        pass

    @classmethod
    def class_method(cls):          # 操作类，第一个参数 cls（类本身）
        return cls.count

    @staticmethod
    def static_method(x):           # 不依赖实例/类，无 self/cls
        return x * 2

MyClass.class_method()              # 通过类调用
MyClass.static_method(3)            # 6
```

| 类型 | 装饰器 | 首参 | 何时用 |
|------|--------|------|--------|
| 实例方法 | 无 | `self` | 操作实例属性 |
| 类方法 | `@classmethod` | `cls` | 操作类属性 / 工厂方法 |
| 静态方法 | `@staticmethod` | 无 | 与类无关的工具函数 |

## @property（getter / setter）

```python
class Circle:
    def __init__(self, r):
        self._r = r

    @property
    def r(self):                # getter
        return self._r

    @r.setter
    def r(self, value):         # setter，可加校验
        if value < 0:
            raise ValueError("半径不能为负")
        self._r = value

    @property
    def area(self):             # 只读属性（由其它属性算出）
        return 3.14 * self._r ** 2

c = Circle(5)
print(c.r, c.area)     # 5 78.5
c.r = 10               # 走 setter
```

> ↔ Java 的 `getX()` / `setX()`，Python 用 `@property` 让属性访问像字段一样。

## 与 Java 对比总结

| 项 | Python | Java |
|----|--------|------|
| 定义 | `class X:` + 缩进 | `class X {}` |
| 实例化 | `X()` 无 `new` | `new X()` |
| 构造 | `__init__(self)` | 构造方法 |
| this | `self`（显式首参） | `this`（隐式） |
| 私有 | 无，下划线约定 | `private` 强制 |
| 继承 | `class D(A)`，支持多继承 | `extends`，类单继承 |
| 接口 | 无（鸭子类型） | `interface` / `implements` |
| 方法重载 | 无（用默认参数） | 支持 |
| 方法覆写 | 直接重写 | `@Override` |
| 静态方法 | `@staticmethod` | `static` |
| getter/setter | `@property` | `getX()` / `setX()` |
| toString | `__str__` / `__repr__` | `toString()` |
| equals | `__eq__` | `equals()` |
