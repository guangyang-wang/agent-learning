# Python 复习速查

> 五容器 + 函数 + 模块，一张卡快速回忆。Java 对照见每节末尾。

## 一、容器总览

| 容器 | Java 对应 | 可变 | 有序 | 可重复 | 备注 |
|------|-----------|------|------|--------|------|
| list | `ArrayList` | ✅ | ✅ | ✅ | 最常用 |
| str | `String` | ❌ | ✅ | ✅ | 无 char |
| tuple | `List.of()` | ❌ | ✅ | ✅ | 可哈希，可作 dict 键 |
| dict | `HashMap` | ✅ | 3.7+ 保序 | 键唯一 | 键必须可哈希 |
| set | `HashSet` | ✅ | ❌ 无序 | ❌ 去重 | 元素可哈希 |

**共同点**：都能索引/切片（str、list、tuple）、遍历、`len()`、`in` 判断。

## 二、List

```python
[] / list()                      # 定义
nums[0]  nums[-1]                # 正负索引
nums[start:end:step]             # 切片，左闭右开，越界不报错
nums[::-1]                       # 反转
```

| 方法 | 作用 | 方法 | 作用 |
|------|------|------|------|
| `append(x)` | 末尾加 | `index(x)` | 首个下标 |
| `insert(i,x)` | 指定位置插 | `count(x)` | 次数 |
| `extend(seq)` | 追加序列 | `sort()`/`reverse()` | 排序/反转 |
| `remove(x)` | 删首个 | `pop(i)` | 删并返回 |
| `a + b` / `[*a,*b]` / `a*2` | 拼接/重复 | `enumerate` | 遍历下标+元素 |

> Java：`add` / `remove` / `size()`；越界 `IndexError`。

## 三、字符串 str

**不可变**：所有方法返回新串，原串不变。没有 `char`。

```python
s[::-1]                 # 反转
"a,b".split(",")        # ['a','b']
"-".join(["a","b"])     # 'a-b'
s.strip()  s.find("x")  # find 找不到返回 -1，index 抛异常
s.upper() s.lower() s.replace(old,new) s.startswith(x) s.isdigit()
f"{name} got {score:.1f}"   # f-string（推荐）
ord('a')  chr(97)  s.encode()  b.decode()
```

---

## 四、元组 tuple

**不可变**：只能查，不能增删改。只有 `count()` / `index()` 两个方法。

```python
(1,)                    # 单元素元组，逗号不能省（(1) 是数字）
t[1].append(4)          # 可改「可变元素」内部，顶层不可赋值
a, *rest = (1,2,3,4)    # 解包：a=1, rest=[2,3,4]
x, y = y, x             # 交换
```

## 五、字典 dict

```python
d["k"]                  # 取值，键不存在抛 KeyError
d.get("k", 默认)        # 取值，不存在返回默认（安全）
d["new"] = v            # 键不存在即新增
```

| 方法 | 作用 | 方法 | 作用 |
|------|------|------|------|
| `keys()`/`values()`/`items()` | 键/值/键值对 | `pop(k)` | 删并返回 |
| `get(k,d)` | 安全取值 | `setdefault(k,v)` | 无则设默认 |
| `update(d2)` | 合并 | `d1 \| d2` / `{**d1,**d2}` | 合并（后者覆盖） |

```python
for k, v in d.items():        # 遍历（最常用）
{x: x**2 for x in range(3)}   # 字典推导式

from collections import defaultdict, Counter
defaultdict(int)              # ≈ computeIfAbsent，键不存在自动建默认值
Counter("hello")              # 一键统计频次
```

## 六、集合 set

**无序、去重**，不能索引/切片。

```python
set()                 # 空集合（{} 是空字典！）
{1,2,3}               # 字面量，自动去重
s.add(4)  s.remove(2) # remove 不存在抛错，discard 不报错
a | b  a & b  a - b  a ^ b    # 并/交/差/对称差
```

## 七、函数

```python
def greet(name):           # 缺省返回 None
    return a, b            # 多返回值 = 元组
```

**参数顺序**：`位置, *args, 默认值, **kwargs`

| 类型 | 写法 | Java 对应 |
|------|------|-----------|
| 默认参数 | `f(x, n=2)` | 方法重载 |
| 关键字参数 | `f(name="Tom")` | 无（Builder） |
| `*args` | 任意位置参数→元组 | `int...` |
| `**kwargs` | 任意关键字参数→字典 | 传 `Map` |

**作用域**：`global` 改全局；`nonlocal` 改外层局部（闭包内用）。

**类型注解**：`def add(a: int, b: int) -> int`，只是提示、运行时不强制（↔ Java 强类型）；`Optional[int]` = `int | None`。

**lambda**：`lambda a,b: a+b`（一个表达式，自动返回）↔ Java 8 Lambda。

**高阶函数**（返回惰性对象，要 `list()`）：
```python
list(map(fn, nums))  list(filter(fn, nums))
sorted(nums, key=fn) reduce(fn, nums)   # from functools import reduce
```

**闭包**：返回内层函数，用 `nonlocal` 记住外层状态。

**装饰器**：`@timer` = `say = timer(say)` ↔ Java AOP。

**生成器**：`yield` 暂停返回，惰性生成 ↔ Java `Iterator`。

## 八、模块

```python
import math                 # 导入整个模块，用 math.sqrt
from math import sqrt       # 只导入指定，直接用 sqrt
import math as m            # 起别名
```

**入口判断**：`if __name__ == "__main__":` 直接运行才执行，被 import 时跳过。

**层级结构**：Python「包 → 模块 → 函数/类」，Java「模块 → 包 → 类」（谁装谁对调）。

| 常用模块 | 作用 | Java 对应 |
|---------|------|-----------|
| `os` | 系统/路径 | `java.io.File` |
| `sys` | 解释器/命令行参数 | `System` |
| `math` | 数学 | `java.lang.Math` |
| `random` | 随机数 | `java.util.Random` |
| `datetime` | 日期时间 | `java.time` |
| `json` | JSON 序列化 | Jackson / Gson |
| `re` | 正则 | `java.util.regex` |

第三方库 `pip install 包名` ↔ Maven / Gradle。

## 九、速记易错点

- `(1)` 是数字，`(1,)` 才是元组
- `{}` 是空字典，空集合用 `set()`
- str / tuple 不可变，list / dict / set 可变
- `d[k]` 抛 `KeyError`，`d.get(k)` 返回 `None`
- list 不能作 dict 的 key 或放进 set（不可哈希），tuple 可以
- `map`/`filter` 是惰性对象，要 `list()` 才出结果
- 可变默认参数（list）会共享，用 `n=None` 兜底
- 避免 `import *`（易命名冲突）；模块找不到抛 `ModuleNotFoundError`
