# Python 函数（Function）速查

相当于 Java 的**方法**。用 `def` 定义，缩进表示函数体，缺省返回 `None`。

## 定义
```python
def greet(name):
    """文档字符串"""
    return f"Hello, {name}"   # 没写 return 则默认返回 None
```

## 返回值
```python
return a, b        # 多返回值，底层是元组
x, y = swap(1, 2)  # 解包
```

## 参数（重点）
| 类型 | 写法 | 说明 | Java 对应 |
|------|------|------|-----------|
| 位置参数 | `f(a, b)` | 按位置对应 | 普通参数 |
| 默认参数 | `f(x, n=2)` | 可省略，**替代重载** | 方法重载 |
| 关键字参数 | `f(name="Tom")` | 指名传参 | 无（Builder） |
| `*args` | `f(*nums)` | 任意个位置参数→**元组** | `int... args` |
| `**kwargs` | `f(**kw)` | 任意个关键字参数→**字典** | 传 `Map` |

**参数顺序**：`位置参数, *args, 关键字参数=默认值, **kwargs`

```python
def f(a, b=2, *args, **kwargs): ...
```

> 易错：可变默认值（list）会共享，用 `n=None` 再在函数内创建。

## 作用域
| 关键字 | 作用 |
|--------|------|
| 默认 | 局部优先，只读外层 |
| `global` | 函数内修改全局变量 |
| `nonlocal` | 嵌套函数内修改外层局部变量 |

## lambda（匿名函数）
```python
add = lambda a, b: a + b    # 只能一个表达式，自动返回
```
> ↔ Java 8 Lambda（Python 无需函数式接口）。

## 高阶函数（函数是一等公民）
```python
list(map(lambda x: x*2, nums))          # [2,4,6,8]
list(filter(lambda x: x%2==0, nums))    # [2,4]
sorted(nums, key=lambda x: -x)          # 按 key 排序
reduce(lambda a,b: a+b, nums)           # 累加（from functools import reduce）
```
> `map`/`filter` 返回**惰性对象**，要 `list()` 才出结果。

## 闭包
```python
def make_counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc        # 返回内层函数，记住外层状态
```

## 装饰器（@语法糖，不改原函数加功能）
```python
@timer               # 等价 say = timer(say)
def say(name): ...
```
> ↔ Java AOP / 动态代理。

## 生成器 yield
```python
def count(n):
    i = 0
    while i < n:
        yield i      # 暂停返回，下次继续
        i += 1
```
> ↔ Java `Iterator`，惰性生成省内存。

## 与 Java 对比
| 项 | Python | Java |
|----|--------|------|
| 定义 | `def` + 缩进 | 方法 + `{}` |
| 无返回值 | 默认 `None` | `void` / `null` |
| 默认参数 | `f(x=1)` | 重载 |
| 多返回值 | `return a, b` | 自定义类 / record |
| 可变参数 | `*args`（元组） | `int...`（数组） |
| 关键字参数 | 支持 | 无 |
| 匿名函数 | `lambda` | Lambda + 函数式接口 |
| 改外层变量 | `global`/`nonlocal` | 遮蔽报错 |
| 装饰器 | `@` 语法糖 | AOP |
| 生成器 | `yield` | `Iterator` |
