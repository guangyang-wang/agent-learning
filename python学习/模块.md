# Python 模块（Module）

相当于 Java 的**包 + import 机制**。一个 `.py` 文件就是一个模块，文件名即模块名。

## 什么是模块
- 一个 `.py` 文件 = 一个模块（`math.py` → 模块 `math`）
- 作用：代码复用、命名空间隔离、逻辑拆分

## 导入方式（重点）

```python
import math                 # 导入整个模块
print(math.sqrt(9))         # 3.0，用「模块名.函数」调用

from math import sqrt       # 只导入指定函数
print(sqrt(9))              # 3.0，直接用，不用前缀

import math as m            # 模块起别名
print(m.sqrt(9))

from math import sqrt as sq # 函数起别名
from math import *          # 全部导入（不推荐，易命名冲突）
```

| Python | Java |
|--------|------|
| `import math` | `import java.util.*` |
| `from math import sqrt` | `import static java.lang.Math.sqrt` |
| `import math as m` | 无（用全限定名代替） |

> 推荐 `import 模块` 或 `from 模块 import 具体名字`，避免 `import *`。

## 模块 vs 脚本：`__name__`

```python
# my_module.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    # 只有「直接运行本文件」时才执行，被 import 时跳过
    print(add(1, 2))
```

- 直接运行脚本：`__name__ == "__main__"`
- 被 `import` 时：`__name__ == 模块名`（如 `"my_module"`）
- 作用：同一份代码既能当脚本跑，又能被 import 而不触发测试代码

> Java 没有对应概念，Java 的入口是固定的 `public static void main`。

## 包（Package）

- 目录 + `__init__.py` = 包（`__init__.py` 可空，标记这是包）
- Python 3.3+ 可省略 `__init__.py`（命名空间包）

```python
from 包名.模块名 import 函数
from utils.math_tools import add   # utils/ 目录下的 math_tools.py
```

### 层级结构：包里有模块 vs 模块里有包

Python 是「**包 → 模块 → 函数/类**」，Java 反过来是「**模块 → 包 → 类**」——同一层级，谁装谁正好对调。

```
Python：  包 package（目录）
          └── 模块 module（.py 文件）
              └── 函数 / 类

Java：    模块 module（Java 9+，module-info.java）
          └── 包 package（目录）
              └── 类 class（.java 文件）
```

| 层级 | Python | Java |
|------|--------|------|
| 第 1 层（最外层） | 包 package | 模块 module |
| 第 2 层 | 模块 module | 包 package |
| 第 3 层（最内层） | 函数 / 类 | 类 class |

> 易混：Python 的「包」和 Java 的「包」都是**目录**，但 Python 包里装的是**模块**，Java 包里装的是**类**；Java 9+ 的「模块」是比包更大的层级（Java 9 之前没有，只有「包 → 类」），Python 没有对应概念。

## 常用标准库速查

| 模块 | 作用 | Java 对应 |
|------|------|-----------|
| `os` | 系统操作、路径 | `java.io.File` / `System` |
| `sys` | 解释器信息、命令行参数 | `System` |
| `math` | 数学函数、常量 | `java.lang.Math` |
| `random` | 随机数 | `java.util.Random` |
| `datetime` | 日期时间 | `java.time` |
| `time` | 时间戳、延时 | `System.currentTimeMillis` |
| `json` | JSON 序列化 / 反序列化 | Jackson / Gson |
| `re` | 正则表达式 | `java.util.regex` |

```python
import os
os.getcwd()                    # 当前目录
os.path.join("a", "b")         # 拼接路径（Windows 为 'a\\b'）

import sys
sys.argv                       # 命令行参数列表
sys.path                       # 模块搜索路径

import math
math.sqrt(9)  math.pi  math.floor(3.7)   # 3.0  3.1415...  3

import random
random.randint(1, 10)          # 1~10 随机整数（含两端）
random.choice([1, 2, 3])       # 随机选一个
random.random()                # [0,1) 随机浮点

from datetime import datetime
datetime.now()                 # 当前时间

import json
json.dumps({"a": 1})           # '{"a": 1}'  字典 → JSON 字符串
json.loads('{"a": 1}')         # {'a': 1}    JSON 字符串 → 字典

import re
re.search(r"\d+", "abc123").group()   # '123' 匹配数字
```

## 第三方库

```bash
pip install requests           # 安装第三方库
pip list                       # 查看已安装
import requests                # 安装后即可 import
```

> 对应 Java 的 Maven / Gradle 依赖，`pip` 是 Python 的包管理器。

## 模块搜索路径

`import` 时按 `sys.path` 顺序查找：
当前目录 → 环境变量 `PYTHONPATH` → 标准库 → 第三方库（site-packages）

> 找不到会抛 `ModuleNotFoundError`（对应 Java 的 `ClassNotFoundException`）。

## 与 Java 对比总结

| 项 | Python | Java |
|----|--------|------|
| 代码组织单位 | 模块（.py 文件） | 类（.java 文件） |
| 导入 | `import` / `from...import` | `import` |
| 包 | 目录 + `__init__.py` | 目录 + 包名 |
| 静态导入 | `from math import sqrt` | `import static` |
| 入口 | `if __name__ == "__main__"` | `main()` 方法 |
| 包管理 | `pip` | Maven / Gradle |
| 找不到 | `ModuleNotFoundError` | `ClassNotFoundException` |
