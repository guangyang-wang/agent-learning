# Python 列表（List）

相当于 Java 的 **ArrayList**：有序、可变、可重复、可存不同类型、动态扩容。

## 定义
```python
[]               # 空列表
list()           # 空列表
[1, "a", 3.14]   # 可混合不同类型
list("abc")      # ['a', 'b', 'c'] 由容器转换
```

## 常用操作
```python
fruits = ["apple", "banana", "orange"]

fruits[0]           # apple
fruits[-1]          # orange（倒数第一个）
fruits[1] = "g"     # 修改
"apple" in fruits   # True 是否在列表中
"grape" not in fruits   # True 是否不在
```

| 方法 | 作用 | 方法 | 作用 |
|------|------|------|------|
| `append(x)` | 末尾添加 | `index(x)` | 首个匹配下标 |
| `insert(i,x)` | 指定位置插入 | `count(x)` | 出现次数 |
| `extend(seq)` | 追加序列 | `sort()` | 原地排序 |
| `remove(x)` | 删首个匹配 | `reverse()` | 原地反转 |
| `pop(i)` | 删并返回（默认末尾） | `clear()` | 清空 |
| `len(l)` | 长度（内置函数） | | |

```python
a = [1, 2]; b = [3, 4]
a + b       # [1,2,3,4] 拼接，返回新列表
[*a, *b]    # 解包拼接，任意位置混入
a * 2       # [1,2,1,2] 重复
a += b      # 原地扩展 = extend(b)

for x in fruits:               # 遍历元素
for i, x in enumerate(fruits): # 遍历下标+元素
```

## 索引
- 正数 `0~len-1`；负数 `-1`(末尾) ~ `-len`(开头)
- `list[i] == list[i+len]`；越界抛 `IndexError`

| 元素 | apple | banana | orange |
|------|-------|--------|--------|
| 正数 | 0 | 1 | 2 |
| 负数 | -3 | -2 | -1 |

> 是「负数索引」不是「复数」——复数（`3+4j`）是数字类型，不能做索引。

## 切片
`list[start:end:step]`，**左闭右开**

```python
nums = [1,2,3,4,5]
nums[1:3]   # [2,3]
nums[:3]    # [1,2,3] 从头
nums[2:]    # [3,4,5] 到末尾
nums[:]     # 复制
nums[::2]   # [1,3,5] 隔一个取
nums[::-1]  # [5,4,3,2,1] 反向
nums[-2:]   # [4,5]
```

| 省略 | 默认 |
|------|------|
| start | 0（负步长=末尾） |
| end | len（负步长=开头） |
| step | 1 |

- 越界**不报错**，自动截断；`step` 为负 = 从右往左

## 与 Java 对比
| 项 | Python | Java |
|----|--------|------|
| 泛型 | 无 | `<T>` |
| 声明 | `[]`/`list()` | `new ArrayList<>()` |
| 添加 | `append`/`insert` | `add` |
| 删除 | `remove`/`pop` | `remove` |
| 长度 | `len(l)` | `size()` |
| 越界 | `IndexError` | `IndexOutOfBoundsException` |

# Python 字符串（str）

相当于 Java 的 **String**：有序、**不可变**、可索引、可切片、可遍历。Python **没有 char 类型**，单个字母 `'a'` 就是长度为 1 的字符串。

## 定义
```python
'a'                  # 单字符也是字符串，没有 char
"abc"                # 单引号 / 双引号等价
'''多行
字符串'''            # 三引号可跨行（""" ... """ 同理）
str(123)             # '123' 类型转换
r"c:\new"            # 原始字符串，\ 不转义
```

## 核心特性：不可变
```python
s = "abc"
s[0] = "x"        # TypeError! 不可原地修改
s = s + "d"       # 生成新对象，不是改原对象
```
> 与 list 相反：list 可变，str 不可变。所有字符串方法都**返回新字符串**，原串不变。

## 索引与切片
和列表**完全一样**：正负索引、`[start:end:step]` 左闭右开、越界自动截断。
```python
s = "python"
s[0]      # 'p'
s[-1]     # 'n'
s[1:4]    # 'yth'
s[::-1]   # 'nohtyp' 反转

for ch in s:                 # 遍历字符
for i, ch in enumerate(s):   # 遍历 下标+字符
```

## 常用操作
```python
s = "py"; t = "thon"
s + t         # 'python' 拼接
s * 3         # 'pypypy' 重复
"y" in s      # True 成员判断
len(s)        # 2
```

## 常用方法（速查）

| 方法 | 作用 | 方法 | 作用 |
|------|------|------|------|
| `upper()` / `lower()` | 全大写 / 小写 | `strip()` | 去两端空白（可指定字符） |
| `capitalize()` | 首字母大写 | `lstrip()` / `rstrip()` | 去左 / 右空白 |
| `title()` | 每个单词首字母大写 | `split(sep)` | 按分隔符切分 → list |
| `swapcase()` | 大小写互换 | `join(iterable)` | 用分隔符拼接 |
| `find(x)` | 首个下标，找不到 **-1** | `replace(old,new,n)` | 替换（n 为最大次数） |
| `rfind(x)` | 从右往左找 | `count(x)` | 出现次数 |
| `index(x)` | 同 find，找不到**抛异常** | `startswith(x)` / `endswith(x)` | 判断前缀 / 后缀 |
| `isdigit()` | 是否全数字 | `zfill(n)` | 左侧补 0 到 n 位 |

```python
" a,b,c ".strip()      # 'a,b,c'
"a,b,c".split(",")     # ['a', 'b', 'c']
"-".join(["a", "b"])   # 'a-b'
"abc".find("d")        # -1（index 会抛 ValueError）
"abc".replace("a", "x") # 'xbc'
"12".isdigit()         # True
```

## 转义字符
```python
"\n" 换行    "\t" 制表符    "\\" 反斜杠    "\'" 单引号
r"\n"        # 原始字符串，保留字面 \n
```

## 格式化（推荐 f-string）
```python
name = "Tom"; score = 92.5
f"{name} got {score}"     # 'Tom got 92.5'
f"{score:.1f}"            # '92.5' 保留一位小数
f"{name:>10}"             # '       Tom' 右对齐占 10 位

"{0} and {1}".format(1, 2)  # 旧式 .format
"%s" % name                 # 更旧的 % 格式化
```

## 字符与编码
```python
ord('a')             # 97    字符 → 码点
chr(97)              # 'a'   码点 → 字符
s.encode('utf-8')    # str → bytes
b.decode('utf-8')    # bytes → str
```

## 与 Java 对比
| 项 | Python | Java |
|----|--------|------|
| char 类型 | 无（单字符即 str） | `char` |
| 可变性 | 不可变 | 不可变 |
| 拼接 | `+` 或 `''.join()` | `+` / `StringBuilder` |
| 长度 | `len(s)` | `s.length()` |
| 取字符 | `s[i]` | `s.charAt(i)` |
| 子串 | `s[a:b]` 切片 | `s.substring(a, b)` |
| 判等 | `==`（比较值） | `equals()` |
| 替换 | `s.replace()` 返回新串 | `s.replace()` |
| 格式化 | f-string | `String.format` / `%s` |

# Python 元组（Tuple）

相当于 Java 的 **`List.of()` 不可变 List**：有序、**不可变**、可重复、可索引、可切片、可遍历。Java **没有原生元组类型**。

## 定义
```python
()                  # 空元组
tuple()             # 空元组，类似于强制类型转换，把null转为了空的元组
(1, 2, 3)           # 多元素元组
(1,)                # 单元素元组，逗号不能省！
1, 2, 3             # 无括号也能建元组（少见），这里是组包
tuple("abc")        # ('a', 'b', 'c')
tuple([1, 2])       # (1, 2) 由 list 转换
```

## 核心特性：不可变（只能查，不能改）
```python
t = (1, 2, 3)
t[0]            # 1    能查
t[0] = 9        # TypeError! 不能改
t.append(4)     # AttributeError! 没有这个方法
del t[0]        # TypeError! 不能删
```
> 与 list 相反：list 可变，tuple 不可变。所以 tuple **只有查询类方法**，没有任何增删改方法。

## 常用操作（和 list 相同的部分）
```python
t = (1, 2, 3, 2)
t[0]            # 1       正负索引
t[-1]           # 2
t[1:3]          # (2, 3)  切片，返回新元组
2 in t          # True
len(t)          # 4
t.count(2)      # 2
t.index(3)      # 2

for x in t:                 # 遍历元素
for i, x in enumerate(t):   # 遍历 下标+元素
```

## 方法（速查）——只有这两个
| 方法 | 作用 |
|------|------|
| `count(x)` | 出现次数 |
| `index(x)` | 首个匹配下标 |

> list 有的 `append/insert/extend/remove/pop/sort/reverse/clear`，tuple **全都没有**，因为它们都会「修改」，而元组不可修改。

## 解包（unpacking）
```python
a, b = (1, 2)          # a=1, b=2
a, b = 1, 2            # 右端可省括号
a, *rest = (1,2,3,4)   # a=1, rest=[2,3,4]
x, y = y, x            # 交换两个变量的经典写法
```

## 易错点
```python
(1)          # 1，这是普通数字，括号只是优先级
(1,)         # (1,)，单元素元组必须加逗号

t = (1, [2, 3])
t[1].append(4)   # 可以！变成 (1, [2,3,4])
t[0] = 5         # TypeError! 顶层元素不可改
```
> 「元组不可变」指的是**顶层元素不可重新赋值**；如果元素本身是可变对象（如 list），那个对象内部仍可修改。

## 为什么用元组
- 不可被意外修改，更安全
- **可哈希** → 能作 dict 的 key、放进 set（list 不行）
- 函数返回多个值，底层就是元组
- 相比 list 更省内存、略快

## 与 Java 对比
| 项 | Python | Java |
|----|--------|------|
| 对应类型 | tuple | 无原生元组，近似 `List.of()` |
| 可变性 | 不可变 | `List.of()` 不可变 |
| 定义 | `()` / `tuple()` | `List.of(1,2,3)` |
| 单元素 | `(1,)` | `List.of(1)` |
| 修改 | 不支持（无方法） | `List.of()` 不支持 `add/remove/set` |
| 作 Map 的 key | 可哈希，能作 dict 的 key | 无对应 |
| 多返回值 | 函数返回多个值 | 需自定义类 / record |

# Python 字典（dict）

相当于 Java 的 **HashMap**：键值对存储、键唯一、可增删改查。键必须**可哈希**（不可变），值任意。Python 3.7+ 保持插入顺序。

## 定义
```python
{}                       # 空字典
dict()                   # 空字典
{"name": "Tom", "age": 18}
dict(name="Tom", age=18)            # 关键字参数建字典
dict([("name","Tom"),("age",18)])   # 由键值对序列转换
```

## 存取（核心）
```python
d = {"name": "Tom", "age": 18}
d["name"]            # 'Tom' 取值
d["age"] = 20        # 修改
d["city"] = "NY"     # 新增（键不存在即新增）
"name" in d          # True 判断键是否存在
d.get("name")        # 'Tom'
d.get("city", "未知") # '未知' 键不存在返回默认值
```
> `d["key"]` 键不存在会抛 `KeyError`；`d.get("key")` 键不存在返回 `None`（可指定默认值）。

## 常用方法（速查）

| 方法 | 作用 | 方法 | 作用 |
|------|------|------|------|
| `keys()` | 所有键 | `values()` | 所有值 |
| `items()` | 所有键值对 | `get(k, d)` | 取值，无则返回默认 |
| `pop(k)` | 删并返回值 | `popitem()` | 删并返回末项 |
| `update(d2)` | 合并更新 | `clear()` | 清空 |
| `setdefault(k, v)` | 无此键则设默认值 | `len(d)` | 键值对数量 |

```python
d = {"a": 1, "b": 2}
d["c"] = 3                  # 新增
d.update({"d": 4, "e": 5})  # 批量合并
d.pop("a")                  # 1，删除键 a
d.setdefault("f", 0)        # 若 f 不存在则 d["f"]=0
list(d.keys())              # ['b','c','d','e','f']
```

## 合并字典（Python 3.9+）
```python
d1 = {"a": 1}
d2 = {"b": 2, "a": 9}

d1 | d2            # {'a': 9, 'b': 2} 合并，键重复时后者覆盖
d1 |= d2           # 原地合并 = update(d2)
{**d1, **d2}       # 解包合并，同样后者覆盖
d1.update(d2)      # 原地合并（所有版本通用）
```
> Java 合并两个 Map 没有语法糖，得 `map1.putAll(map2)`。

## 进阶：defaultdict 与 Counter
```python
from collections import defaultdict, Counter

# defaultdict：键不存在时自动用默认值创建，省去先判断
cnt = defaultdict(int)
cnt["a"] += 1          # 'a' 不存在也直接 +1，默认 0
cnt = defaultdict(list)
cnt["x"].append(1)     # 自动创建空 list

# Counter：一键统计频次
Counter("hello")       # Counter({'l': 2, 'h': 1, 'e': 1, 'o': 1})
Counter([1,2,2,3])     # Counter({2: 2, 1: 1, 3: 1})
```
> `defaultdict` ≈ Java `computeIfAbsent`；`Counter` 相当于 Java 手动写的频次统计 Map。

## 遍历
```python
d = {"a": 1, "b": 2}
for k in d:              # 遍历键（默认）
for k, v in d.items():   # 遍历 键+值（最常用）
for v in d.values():     # 遍历值
```

## 字典推导式
```python
{x: x**2 for x in range(3)}              # {0:0, 1:1, 2:4}
{k: v for k, v in d.items() if v > 1}    # 带条件
```

## 易错点
- **键必须可哈希（不可变）**：list 不能作 key，tuple 可以
- 键重复时，后者覆盖前者：`{"a":1, "a":2}` → `{'a': 2}`
- `d["key"]` 与 `d.get("key")` 的区别（见上）

## 与 Java 对比
| 项 | Python | Java |
|----|--------|------|
| 对应类型 | dict | HashMap |
| 定义 | `{}` / `dict()` | `new HashMap<>()` |
| 存取 | `d[k]` / `d[k]=v` | `get(k)` / `put(k,v)` |
| 键不存在 | `d[k]` 抛 KeyError，`get` 返回 None | `get` 返回 null |
| 取默认值 | `d.get(k, v)` | `getOrDefault(k, v)` |
| 无键则设 | `d.setdefault(k, v)` | `computeIfAbsent` / `putIfAbsent` |
| 合并 | `d1 \| d2` / `update` | `putAll` |
| 键类型 | 必须可哈希（不可变） | 任意对象（需 hashCode/equals） |
| 遍历 | `for k,v in d.items()` | `entrySet()` |
| 有序性 | 3.7+ 保插入序 | HashMap 无序，LinkedHashMap 保序 |

# Python 集合（set）

相当于 Java 的 **HashSet**：**无序、不重复**、可变、元素必须可哈希。自动去重。

## 定义
```python
set()            # 空集合（注意：{} 是空字典！）
{1, 2, 3}        # 集合字面量
set("hello")     # {'h','e','l','o'} 自动去重
set([1,2,2,3])   # {1,2,3} 由 list 去重
```

## 核心特性：去重 + 无序
```python
s = {1, 2, 3, 2}
s            # {1, 2, 3} 重复的 2 自动去掉
s[0]         # TypeError! 无序，不能索引/切片
```

## 常用操作
```python
s = {1, 2, 3}
s.add(4)         # 添加
s.remove(2)      # 删除，不存在抛 KeyError
s.discard(9)     # 删除，不存在不报错（更安全）
s.pop()          # 随机删一个并返回
2 in s           # True 判断存在
len(s)           # 3
```

## 集合运算（Java 要自己写，Python 一行）
```python
a = {1, 2, 3}
b = {2, 3, 4}
a | b    # {1,2,3,4} 并集
a & b    # {2,3}     交集
a - b    # {1}       差集（a 有 b 无）
a ^ b    # {1,4}     对称差（只在一边）
```

## 方法（速查）

| 方法 | 作用 | 方法 | 作用 |
|------|------|------|------|
| `add(x)` | 添加 | `remove(x)` | 删，无则报错 |
| `discard(x)` | 删，无则不报错 | `pop()` | 随机删一个 |
| `union(b)` | 并集 | `intersection(b)` | 交集 |
| `difference(b)` | 差集 | `symmetric_difference(b)` | 对称差 |
| `update(b)` | 原地并集 | `clear()` | 清空 |

## 遍历
```python
for x in s:      # 遍历，顺序不定
```

## 集合推导式
```python
{x for x in range(5)}      # {0,1,2,3,4}
{x for x in "hello"}       # {'h','e','l','o'}
```

## 易错点
- `{}` 是**空字典**，空集合必须用 `set()`
- 元素必须可哈希：list 不能放进 set，tuple 可以
- 无序：不能索引、不能切片

## 与 Java 对比
| 项 | Python | Java |
|----|--------|------|
| 对应类型 | set | HashSet |
| 定义 | `set()` / `{1,2,3}` | `new HashSet<>()` |
| 空集合 | `set()`（`{}` 是字典） | `new HashSet<>()` |
| 添加 | `add(x)` | `add(x)` |
| 删除 | `remove` / `discard` | `remove` |
| 判存在 | `x in s` | `contains(x)` |
| 并/交/差 | `\|` `&` `-` `^` | 需自写（retainAll 等） |
| 无序性 | 无序，不能索引 | 无序 |
