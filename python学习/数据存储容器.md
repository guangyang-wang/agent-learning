# Python 列表（List）

相当于 Java 的 **ArrayList**：有序、可变、可重复、可存不同类型、动态扩容。

## 定义
```python
[]               # 空列表
list()           # 空列表
[1, "a", 3.14]   # 可混合不同类型
list("abc")      # ['a', 'b', 'c'] 由容器转换
```

## 常用操作
```python
fruits = ["apple", "banana", "orange"]

fruits[0]           # apple
fruits[-1]          # orange（倒数第一个）
fruits[1] = "g"     # 修改
"apple" in fruits   # True 是否在列表中
"grape" not in fruits   # True 是否不在
```

| 方法 | 作用 | 方法 | 作用 |
|------|------|------|------|
| `append(x)` | 末尾添加 | `index(x)` | 首个匹配下标 |
| `insert(i,x)` | 指定位置插入 | `count(x)` | 出现次数 |
| `extend(seq)` | 追加序列 | `sort()` | 原地排序 |
| `remove(x)` | 删首个匹配 | `reverse()` | 原地反转 |
| `pop(i)` | 删并返回（默认末尾） | `clear()` | 清空 |
| `len(l)` | 长度（内置函数） | | |

```python
a = [1, 2]; b = [3, 4]
a + b       # [1,2,3,4] 拼接，返回新列表
[*a, *b]    # 解包拼接，任意位置混入
a * 2       # [1,2,1,2] 重复
a += b      # 原地扩展 = extend(b)

for x in fruits:               # 遍历元素
for i, x in enumerate(fruits): # 遍历下标+元素
```

## 索引
- 正数 `0~len-1`；负数 `-1`(末尾) ~ `-len`(开头)
- `list[i] == list[i+len]`；越界抛 `IndexError`

| 元素 | apple | banana | orange |
|------|-------|--------|--------|
| 正数 | 0 | 1 | 2 |
| 负数 | -3 | -2 | -1 |

> 是「负数索引」不是「复数」——复数（`3+4j`）是数字类型，不能做索引。

## 切片
`list[start:end:step]`，**左闭右开**

```python
nums = [1,2,3,4,5]
nums[1:3]   # [2,3]
nums[:3]    # [1,2,3] 从头
nums[2:]    # [3,4,5] 到末尾
nums[:]     # 复制
nums[::2]   # [1,3,5] 隔一个取
nums[::-1]  # [5,4,3,2,1] 反向
nums[-2:]   # [4,5]
```

| 省略 | 默认 |
|------|------|
| start | 0（负步长=末尾） |
| end | len（负步长=开头） |
| step | 1 |

- 越界**不报错**，自动截断；`step` 为负 = 从右往左

## 与 Java 对比
| 项 | Python | Java |
|----|--------|------|
| 泛型 | 无 | `<T>` |
| 声明 | `[]`/`list()` | `new ArrayList<>()` |
| 添加 | `append`/`insert` | `add` |
| 删除 | `remove`/`pop` | `remove` |
| 长度 | `len(l)` | `size()` |
| 越界 | `IndexError` | `IndexOutOfBoundsException` |

# Python 字符串（str）

相当于 Java 的 **String**：有序、**不可变**、可索引、可切片、可遍历。Python **没有 char 类型**，单个字母 `'a'` 就是长度为 1 的字符串。

## 定义
```python
'a'                  # 单字符也是字符串，没有 char
"abc"                # 单引号 / 双引号等价
'''多行
字符串'''            # 三引号可跨行（""" ... """ 同理）
str(123)             # '123' 类型转换
r"c:\new"            # 原始字符串，\ 不转义
```

## 核心特性：不可变
```python
s = "abc"
s[0] = "x"        # TypeError! 不可原地修改
s = s + "d"       # 生成新对象，不是改原对象
```
> 与 list 相反：list 可变，str 不可变。所有字符串方法都**返回新字符串**，原串不变。

## 索引与切片
和列表**完全一样**：正负索引、`[start:end:step]` 左闭右开、越界自动截断。
```python
s = "python"
s[0]      # 'p'
s[-1]     # 'n'
s[1:4]    # 'yth'
s[::-1]   # 'nohtyp' 反转

for ch in s:                 # 遍历字符
for i, ch in enumerate(s):   # 遍历 下标+字符
```

## 常用操作
```python
s = "py"; t = "thon"
s + t         # 'python' 拼接
s * 3         # 'pypypy' 重复
"y" in s      # True 成员判断
len(s)        # 2
```

## 常用方法（速查）

| 方法 | 作用 | 方法 | 作用 |
|------|------|------|------|
| `upper()` / `lower()` | 全大写 / 小写 | `strip()` | 去两端空白（可指定字符） |
| `capitalize()` | 首字母大写 | `lstrip()` / `rstrip()` | 去左 / 右空白 |
| `title()` | 每个单词首字母大写 | `split(sep)` | 按分隔符切分 → list |
| `swapcase()` | 大小写互换 | `join(iterable)` | 用分隔符拼接 |
| `find(x)` | 首个下标，找不到 **-1** | `replace(old,new,n)` | 替换（n 为最大次数） |
| `rfind(x)` | 从右往左找 | `count(x)` | 出现次数 |
| `index(x)` | 同 find，找不到**抛异常** | `startswith(x)` / `endswith(x)` | 判断前缀 / 后缀 |
| `isdigit()` | 是否全数字 | `zfill(n)` | 左侧补 0 到 n 位 |

```python
" a,b,c ".strip()      # 'a,b,c'
"a,b,c".split(",")     # ['a', 'b', 'c']
"-".join(["a", "b"])   # 'a-b'
"abc".find("d")        # -1（index 会抛 ValueError）
"abc".replace("a", "x") # 'xbc'
"12".isdigit()         # True
```

## 转义字符
```python
"\n" 换行    "\t" 制表符    "\\" 反斜杠    "\'" 单引号
r"\n"        # 原始字符串，保留字面 \n
```

## 格式化（推荐 f-string）
```python
name = "Tom"; score = 92.5
f"{name} got {score}"     # 'Tom got 92.5'
f"{score:.1f}"            # '92.5' 保留一位小数
f"{name:>10}"             # '       Tom' 右对齐占 10 位

"{0} and {1}".format(1, 2)  # 旧式 .format
"%s" % name                 # 更旧的 % 格式化
```

## 字符与编码
```python
ord('a')             # 97    字符 → 码点
chr(97)              # 'a'   码点 → 字符
s.encode('utf-8')    # str → bytes
b.decode('utf-8')    # bytes → str
```

## 与 Java 对比
| 项 | Python | Java |
|----|--------|------|
| char 类型 | 无（单字符即 str） | `char` |
| 可变性 | 不可变 | 不可变 |
| 拼接 | `+` 或 `''.join()` | `+` / `StringBuilder` |
| 长度 | `len(s)` | `s.length()` |
| 取字符 | `s[i]` | `s.charAt(i)` |
| 子串 | `s[a:b]` 切片 | `s.substring(a, b)` |
| 判等 | `==`（比较值） | `equals()` |
| 替换 | `s.replace()` 返回新串 | `s.replace()` |
| 格式化 | f-string | `String.format` / `%s` |
