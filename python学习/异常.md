# Python 异常（Exception）

相当于 Java 的**异常处理**：`try/except` ↔ `try/catch`。差异：Python 用 `raise`（不是 `throw`）、多一个 `else` 子句、**没有 checked 异常**。

## 基本语法

```python
try:
    x = int("abc")          # 会抛 ValueError
except ValueError as e:     # 捕获指定异常，as e 拿到异常对象
    print("转换失败:", e)    # 转换失败: invalid literal for int()...
else:
    print("没异常才执行")    # try 成功时执行（Java 没有）
finally:
    print("无论如何都执行")  # 收尾：关闭资源等（和 Java 一样）
```

| 子句 | 触发时机 | Java 对应 |
|------|----------|-----------|
| `try` | 监控可能出错的代码 | `try` |
| `except` | 捕获异常 | `catch` |
| `else` | try **成功**时执行 | 无 |
| `finally` | 无论成败都执行 | `finally` |

## 捕获多个异常

```python
try:
    d = {}
    print(d["k"])            # KeyError
except (KeyError, IndexError):   # 一个 except 捕获多种
    print("键或索引错误")
except ValueError:
    print("值错误")
except Exception as e:       # 兜底：捕获其余所有异常
    print("其他错误:", e)
```

- 多个 `except` 从上往下匹配，**先具体后宽泛**
- 裸 `except:`（不带类型）会连 `KeyboardInterrupt` 都捕获，**不推荐**

## 获取异常对象

```python
try:
    1 / 0
except ZeroDivisionError as e:
    print(type(e).__name__)  # ZeroDivisionError
    print(str(e))            # division by zero
```

## 抛出异常 raise

```python
def div(a, b):
    if b == 0:
        raise ValueError("除数不能为 0")   # raise ↔ Java throw
    return a / b

div(1, 0)   # ValueError: 除数不能为 0
```

- `raise` 后跟异常**实例**（或类），不是 `throw new`
- 在 `except` 里写**裸 `raise`** = 原样重新抛出当前异常

```python
try:
    risky()
except ValueError:
    log()       # 记日志
    raise       # 继续往上抛，不吞掉
```

## 自定义异常

```python
class MyError(Exception):      # 继承 Exception
    pass

raise MyError("自定义错误")
```

> 和 Java 一样，自定义异常继承 `Exception`（Java 是 `extends Exception`）。

## 常见内置异常速查

| 异常 | 触发 | Java 对应 |
|------|------|-----------|
| `ValueError` | 类型对但值不对（`int("abc")`） | `IllegalArgumentException` |
| `TypeError` | 类型不对（`1 + "a"`） | `ClassCastException` |
| `KeyError` | 字典键不存在 | 无（Map 返回 null） |
| `IndexError` | 列表/序列越界 | `IndexOutOfBoundsException` |
| `AttributeError` | 属性/方法不存在 | 无（编译期检查） |
| `NameError` | 变量未定义 | 编译错误 |
| `ZeroDivisionError` | 除以 0 | `ArithmeticException` |
| `FileNotFoundError` | 文件不存在 | `FileNotFoundException` |
| `ImportError` | 导入失败 | `ClassNotFoundException` |

## 与 Java 对比总结

| 项 | Python | Java |
|----|--------|------|
| 捕获 | `except 类型 as e` | `catch (类型 e)` |
| 抛出 | `raise X("msg")` | `throw new X("msg")` |
| 重新抛出 | 裸 `raise` | `throw e` |
| `finally` | 相同 | 相同 |
| `else` | 有（try 成功时） | 无 |
| 捕获多个 | `except (A, B)` | `catch (A \| B)`（Java 7+） |
| 异常基类 | `Exception` | `Exception` / `Throwable` |
| checked 异常 | **无**（不强制声明/捕获） | 有（需 `throws` 或捕获） |

> 最大区别：Python **没有 checked 异常**，方法不会强制要求调用方声明或捕获异常——由运行时决定，靠文档和测试保证。
