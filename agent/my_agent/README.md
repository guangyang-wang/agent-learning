# 大学生智能学习助手 Agent

> 面向大学生的一站式 AI 学习助手：上传课件 / 教材 / 试卷构建**私有知识库**，提供课程答疑、作业辅导、错题诊断、个性化复习，并在交互中**持续收集用户特点**，越用越懂你。

## 二、核心功能详解

### 2.1 私有知识库（上传即建库）

学生把课程资料上传后，系统自动完成「解析 → 分块 → 向量化 → 入库」，形成**个人隔离**的私有向量库。

| 优先级 | 数据源 | 内容 |
|---|---|---|
| 高 | 用户私有上传库 | 课件、教材、实验指导书、往年试卷 |
| 中 | 个人学习沉淀库 | 历史代码、实验报告、错题、学习记录 |
| 低 | 公共联网资源 | 兜底补充，检索为空时才回退 |

- 检索结果为空时回退公共知识，并明确标注「未找到课件依据」，避免模型编造。

### 2.2 智能问答

基于学生自有资料回答课程问题，支持 PDF 课件查询、单题计算、概念解释等，快速响应。

### 2.3 作业辅导

针对课程实验 / 大作业等复杂任务，自动完成：规划任务 → 检索资料 → 编写代码 → 运行调试 → 生成实验报告 → 自查漏洞，失败时自动重规划。

### 2.4 用户画像与个性化（越用越懂你）

这是本系统的差异化能力：**在与用户交互中持续收集用户特点**，沉淀成画像，反向优化每一次回答。

| 画像类型 | 内容 | 更新方式 |
|---|---|---|
| 静态画像 | 专业、年级、擅长科目、偏好（喜欢代码演示 vs 文字解释） | 首次交互 + 持续修正 |
| 动态画像 | 薄弱知识点、掌握度（每个知识点 0~100）、易错点 | 从错题与问答记录聚类得出 |
| 交互偏好 | 解释深度、举例风格、是否需要前置知识补充 | 从用户反馈与追问中学习 |

**使用方式**：每次回答前先读画像，据此调整解释深度、是否展开前置知识、用哪种例子，做到「越用越懂你」。

## 三、补充功能详解

### 3.1 错题本与薄弱点诊断
自动记录用户答错 / 卡壳的题，按知识点聚类，输出「知识缺口地图」，作为后续练习与复习计划的输入。

### 3.2 举一反三
针对薄弱知识点，生成同类型变式题，让用户从「会一道」练到「会一类」，避免机械刷题。

### 3.3 个性化复习计划
结合考试时间、薄弱点优先级、掌握度，倒排生成复习计划，支持每日提醒。

### 3.4 答案溯源（防编造）
每个回答都标注引用来源（哪份资料、第几页），检索为空时诚实说「我不知道」，从机制上抑制模型幻觉。

### 3.5 知识点图谱
维护知识点之间的前置依赖关系（如「先懂页表，再学虚拟内存」），回答时提示用户缺失的前置知识。

### 3.6 学习报告与掌握度
统计学习时长、答题正确率、掌握度变化，定期生成可视化学习报告，帮助学生看清进步。

### 3.7 多格式文档解析
支持 PDF / docx / md / txt，扩展图片 OCR 与公式识别，覆盖拍照上传的试卷、板书。
